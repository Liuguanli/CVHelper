# Jobs Folder

每个岗位用一个独立目录，建议命名：

- `company-role-yyyymm`
- 例如：`databricks-data-engineer-202604`

每个岗位目录只放两类东西：

- 输入：JD、公司背景、你的主攻方向
- 结果：统一放在 `outputs/<yyyymmdd>/`

推荐每轮结果至少包含：

- `job_analysis_<yyyymmdd>.md`
- `resume_changes_<yyyymmdd>.md`
- `ats_review_<yyyymmdd>.md`
- `hr_review_<yyyymmdd>.md`
- 简历 PDF
- cover letter PDF
- video script PDF

当前目标岗位总表见：

- `jobs/target_roles.md`

这样做的好处是：

- 每个岗位互不污染
- 你可以回头复用旧岗位的表达
- 后续很容易做批量化和自动化
- 岗位根目录里的文件数量更少，不容易乱
