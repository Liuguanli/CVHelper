# Market Watch

这个目录专门用来放“美国和澳洲范围内，新发现的、和你目标相似，而且和你当前简历及 research 方向匹配的岗位”。

用途：

- 不和你已经决定要投的岗位混在一起
- 把后来新发现的机会集中管理
- 方便我每次帮你看岗位时顺手补充
- 让筛选标准明确围绕你的真实背景，而不是只看公司名气或岗位标题

工作约定：

1. 你已经明确要投的岗位，放在 `jobs/`。
2. 我后来发现的相似岗位，先放在 `market_watch/discovered_roles.md`。
3. 如果其中某个岗位你决定正式准备材料，再为它创建 `jobs/<job-slug>/`。

“提示你”的方式：

- 只要我在检索时发现了新的相关岗位，我会在回复里明确写出“发现了新的相似岗位”。
- 同时我会把它追加到 `market_watch/discovered_roles.md`。
- 如果岗位和你非常匹配，我会额外标注 `high-priority`。
- 每条记录都会说明它和你的 `resume fit` 以及 `research fit`。

什么算“相似岗位”：

- Backend Engineer
- Software Engineer
- Data Infrastructure / Data Engineer
- Database / Query Engine / Storage / Systems
- Applied Scientist / Research Scientist
- ML Systems / Retrieval / Data Systems 相关岗位

什么算“匹配你的简历和 research”：

- 能和你现有简历里的 backend systems, data infrastructure, ingestion, SQL, benchmarking, indexing, retrieval 等经历形成直接映射
- 能和你 PhD / Postdoc 的 research 主题形成直接映射，例如 data systems, query processing, physical design, learned index, benchmarking, spatial data systems
- 可以用你已有论文、项目、GitHub、工业经历来支撑，而不是靠脑补
- 岗位要求即使有 gap，也能用诚实且合理的方式解释，而不是硬贴

地域范围：

- 美国岗位：优先持续追踪

- 支持 remote / relocation 的岗位：优先级可上调
- 其他地区的极强匹配岗位：也可以收录，但会额外说明原因
