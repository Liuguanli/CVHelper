- ML Systems / Retrieval / RAG related roles

## Matching Heuristics

优先记录满足以下条件的岗位：

- 和 backend, data infra, query processing, storage, indexing, benchmarking, data systems 明显相关
- 和 applied / research engineering 明显相关
- 虽然标题不完全匹配，但职责和你的背景高度重叠
- 位于美国或澳洲，或支持 remote / relocation，且公司为大厂或高质量技术公司

另外必须至少满足下面两项中的一项：

- `resume fit`: 可以直接对应到你现有简历中的经历、技术栈、项目或工业经验
- `research fit`: 可以直接对应到你 PhD / Postdoc 的研究主题、论文方向、系统原型或 benchmarking / indexing / query processing 工作

## Strong Match Areas

以下方向优先级更高：

- Database engine / query engine / storage engine
- Data infrastructure / data platform / ingestion / pipeline reliability
- Query processing / optimization / physical design / data layout
- Benchmarking / performance / systems evaluation
- Retrieval / RAG / vector or embedding-based systems
- Applied scientist or research scientist roles with systems or data focus

## Resume Fit Signals

- Python / Java / SQL
- Backend systems
- Data ingestion and data pipelines
- PostgreSQL / BigQuery / PostGIS / pgvector
- Reliability, performance tuning, benchmarking
- RAG and retrieval related system building

## Research Fit Signals

- VLDB / ICDE / ICDEW / ADC related publications or submissions
- Learned indexes
- Spatial indexes and spatial query processing
- Data layout advisory and physical design
- Drift-aware benchmarking and systems evaluation
- AI-driven query processing or LLM-assisted data systems

## Exclusions

- 明显偏前端 / design / product marketing 的岗位
- 纯 manager 岗位
- 明显和你背景无关的 domain specialist 岗位
- 只能靠堆关键词才能勉强贴上的岗位
